# Klarys

> Klarys (formerly ProcSea; legal entity Procsea SA, Rennes, France) is a SaaS eProcurement platform for
> the fresh-food supply chain — seafood, fruit and vegetables, meat and dairy — connecting retail,
> wholesale and foodservice buyers with their suppliers, wholesalers and mareyeurs. Klarys markets API and
> EDI integration with customer ERP, accounting and product-reference systems. Its tenant application runs
> at klarys.app and publishes an RFC 8414 OAuth 2.0 authorization-server metadata document anonymously,
> but no public API reference, OpenAPI document or developer portal.

GENERATED by API Evangelist, not published by Klarys. Klarys serves no llms.txt of its own
(https://www.klarys.io/llms.txt -> 404, https://klarys.app/llms.txt -> 302 to the app shell), so this file
is assembled from the company's public surface and from the artifacts in this repository. Checked
2026-08-17.

## What an agent can and cannot do here

- There is NO public machine-readable contract. A schema endpoint exists at
  https://klarys.app/api/schema/ but returns HTTP 401 to anonymous callers
  (`{"code":1003,"error":"User is unauthenticated"}`) with Content-Type
  `application/vnd.oai.openapi+json` — the OpenAPI is real and customer-gated.
- The OAuth 2.0 authorization server IS public and machine-readable, including its scope list.
- Klarys advertises `mcp:read` and `mcp:write` scopes, so a Model Context Protocol surface exists, but no
  MCP endpoint is anonymously discoverable and no RFC 9728 protected-resource metadata is served.
- No A2A agent card, no security.txt, no OpenID Connect discovery, no published rate limits, no pricing.

## Machine-readable surface

- [OAuth 2.0 authorization server metadata (RFC 8414)](https://klarys.app/.well-known/oauth-authorization-server): HTTP 200 application/json. Issuer `https://klarys.app/api/public/o`. Grants: authorization_code, client_credentials, refresh_token. PKCE S256. Dynamic client registration, revocation and introspection endpoints. Scopes: groups, introspection, mcp:read, mcp:write, read, write.
- [Same document under the issuer path](https://klarys.app/api/public/o/.well-known/oauth-authorization-server): HTTP 200.
